# Stage05E1 — Replicated architecture families

This stage returns to the DNA-first architecture question after the calibrated full-3D P1/P2 branch. It does **not** search for RTs and does not change any mathematical discovery score or rank.

Primary graph (frozen before locus-level review): N1/N2 candidate loci are linked only when they share **both** (i) at least one Stage05D4R1 FAM50 protein family represented by an ORF within 250 bp of the mathematical candidate and (ii) at least one reverse-complement-canonicalized exact repeat core from a high-complexity, full-span-outside-predicted-CDS repeat group overlapping the mathematical candidate. Replicated components require >=2 distinct sequence IDs.

A 1000-bp graph is reported as a sensitivity view only. All 602 N1/N2 candidates remain retained.

The purpose is to identify repeated DNA+protein neighborhood architectures for subsequent locus-level official-annotation, orientation/spacing, partner, and known-system dereplication review. An architecture family is not an ART identity.

Stage05D4-R5/R5C/R5D structure outcomes are deliberately not inputs to family construction or output annotation in this stage; they are reserved for downstream locus-level synthesis.
