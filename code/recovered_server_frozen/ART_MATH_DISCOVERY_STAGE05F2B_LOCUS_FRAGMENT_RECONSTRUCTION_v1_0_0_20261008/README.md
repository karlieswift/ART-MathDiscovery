# ART Mathematical Genome Discovery — Stage05F2B

Locus-level fragment reconstruction for the annotation-independent RT-rescue branch.

Inputs:
1. Stage05F1 live directory (contains six-frame instances, unique FASTA, RVT domtblout, gate).
2. Stage05F2A live directory or returned result archive/directory.
3. Project root, used only to resolve the frozen Stage05B source manifest/genome FASTAs when needed.

Targeted novelty set: F2A P1/P2/P3 only (16 unique AA; 23 instances in the accepted F2A result). P4 is retained in F2A but not rescanned here. Six known RT calibrations and three prior-D1 bridge AA classes are included as non-discovery controls.

Outputs include target instances, local six-frame hits, same-profile complementary coverage, one-stop readthrough sensitivity, locus-level classification, a structure/profile follow-up queue, and manuscript-facing notes.
